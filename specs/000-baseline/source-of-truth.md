## Positionnement & stratégie (doc stratégie)

- **Ambition** : faire de Maximerit une référence du recrutement, de la mise à disposition de
  talents et des fonctions support en **Afrique de l'Ouest**, spécialisation forte **Mines & Ressources naturelles**.
- **Piliers corporate** : Recrutement, Executive Search, Mise à disposition/intérim, RH & paie, Finance, QHSE, Formation.
- **Verticale prioritaire — 4 territoires Mining** : Géologie & Exploration ; Exploitation & Opérations ; Finance ; Leadership & Executive Search.
- **Cibles** : (1) entreprises minières (décideurs : Country/General/Mine Manager, Exploration Manager, HR Director, TA Manager, Operations Director, CFO, Project Director) ; (2) entreprises industrielles & grands projets (énergie, oil & gas, BTP, infra, industrie, ingénierie) ; (3) talents (géologues, ingénieurs, HSE, finance, maintenance, fonctions support, cadres dirigeants).
- **Modèle** : boucle entreprises ↔ vivier ↔ candidats. Le site alimente cette boucle.
- **Géographie** : marché initial Sénégal ; priorité d'extension : Sénégal, Guinée, Côte d'Ivoire, Mali, Mauritanie, Burkina Faso, Ghana. Positionnement **West Africa**, visible FR **et** EN.
- **4 moteurs d'acquisition simultanés** : SEO, contenu expert, outbound, acquisition candidats.
- **SEO 3 niveaux** : money keywords (→ page commerciale), longue traîne métier (→ page métier/expertise), informationnel stratégique (→ article → expertise → formulaire).
- **Données propriétaires** (levier d'autorité) : Baromètre salaires Mining, baromètre métiers en tension, index de disponibilité des talents, rapport annuel « Mining Talent Outlook West Africa ».
- **Stratégie candidats** : ne pas accumuler des CV mais construire une base **qualifiée et exploitable** (métier, expérience, spécialité, pays, mobilité, langue, salaire, disponibilité, secteur, environnement technique). Valeur = donnée structurée.
- **Top metric** : nombre de besoins de recrutement qualifiés reçus par mois + nombre de talents qualifiés réellement mobilisables dans le vivier.
- **Roadmap 12 mois** : T1 autorité (repositionnement, site, verticale Mining, vivier, premiers contenus piliers, premières fiches métiers) ; T2 couverture (SEO, contenu, pages pays, recrutement candidats, outbound) ; T3 preuve (cas clients, baromètre, témoignages, données, partenariats) ; T4 domination (SEO, backlinks, PR, campagnes, extension géographique).

## Produit & technique (cahier des charges)

- **Objectif** : plateforme d'acquisition commerciale ET de talents, pas un site vitrine.
- **Navigation cible** : Accueil ; Entreprises (Recrutement, Executive Search, Intérim & mise à disposition, Externalisation RH & Paie, Finance & Performance, QHSE & ESG, Formation) ; Secteurs (Mines & Ressources naturelles [PRIORITÉ], Énergie, Pétrole & Gaz, BTP & Infrastructures, Industrie, Services) ; Mining & Resources (Recrutement minier, Géologie & Exploration, Exploitation & Opérations, Finance, Leadership & Executive Search, Métiers miniers, Vivier Mining) ; Candidats (Offres d'emploi, Rechercher une opportunité, Déposer mon CV, Rejoindre le vivier, Conseils carrière) ; Ressources (Blog, Guides, Baromètres, Fiches métiers, Outils gratuits, Études) ; À propos ; Contact. Menu court, sous-pages SEO hors nav principale.
- **Hub Mining** : URL mère `/mines/`, H1 « Recrutement minier en Afrique de l'Ouest », landing page commerciale par pôle.
- **Architecture SEO en silos / clusters sémantiques**. Ex. arbre `/mines/` → `/mines/recrutement-minier/`, `/mines/geologie-exploration/` → `/mines/metiers/geologue-exploration/`, `/mines/metiers/resource-geologist/`, etc.
- **SEO géographique** : matrice MÉTIER × SECTEUR × PAYS ; une page pays seulement si valeur locale spécifique (pas de génération massive quasi-dupliquée). Ex. `/mines/senegal/`, `/mines/guinee/`.
- **Blog** = actif SEO en clusters (catégories : Mining & Resources, Recrutement, RH, Finance, QHSE, Carrière, Salaires, Marché de l'emploi Afrique de l'Ouest). Formats : guides, questions opérationnelles, comparatifs, fiches métiers, données, décideurs.
- **Objectif éditorial cible** : 15–25 pages commerciales, 8–12 secteurs, 7–10 pays, 50+ fiches métiers, 100+ articles, 10+ guides/études, 5–10 outils. Déploiement progressif.
- **Maillage interne** prévu dans le modèle (article → fiche métier → page secteur → page commerciale → conversion ; et article → offres → candidature → vivier). Chaque contenu a une destination de conversion.
- **Outils gratuits** (trafic + backlinks + data + leads) : Calculateur coût d'un recrutement, Calculateur coût employeur (Cost of Vacancy), Benchmark salaire, Mining Team Planner.
- **Plateforme candidats** = module applicatif : Site public → Formulaire candidat → CV → Parsing/données → Base candidats → Qualification → Tags → Recherche → Shortlist → Mission client.
- **Formulaire candidat** — Identité (prénom, nom, email, téléphone, WhatsApp, pays de résidence, nationalité si justifié, mobilité internationale) ; Professionnel (poste actuel, métier recherché, secteur, années d'expérience, niveau hiérarchique, entreprise actuelle, langues, certifications, disponibilité, prétentions salariales, type de contrat) ; Mining (géologie, exploration, exploitation, processing, maintenance, HSE, finance, leadership, commodities, souterraine/ciel ouvert, pays d'expérience, FIFO/roster) ; Pièces (CV PDF/DOCX, lettre facultative, certifications). **Consentement données obligatoire.**
- **CV parsing** : CV → extraction (nom, poste, expériences, employeurs, dates, formation, compétences, langues, pays, certifications) → proposition de fiche. Données **éditables et validables**. CV original attaché au profil.
- **Répertoire candidat interne** (ATS/mini-ERP) : tableau (Candidat, Métier, Exp., Pays, Secteur, Disponibilité, Score, Dernier contact) ; recherche full-text (ex. « geologist gold exploration Senegal ») ; filtres combinables (métier, pays, mobilité, secteur, compétences, expérience, langue, disponibilité, salaire, certification, source, date d'entrée, statut).
- **Tags** : taxonomie **administrée** (pas de création libre). Ex. MINING, GEOLOGY, GOLD, EXPLORATION, SENEGAL, GUINEA, 10+ YEARS, ENGLISH, FRENCH, AVAILABLE, MANAGEMENT.
- **Pipeline recrutement** : Nouveau → À qualifier → Qualifié → Vivier → Présélectionné → Entretien Maximerit → Shortlist client → Entretien client → Offre → Placé (+ états : Indisponible, Refusé, À recontacter, Archivé). Historique complet des changements.
- **Fiche candidat** : identité, CV, expériences, compétences, secteurs, pays/mobilité, rémunération, disponibilité, tags, notes recruteur, entretiens, candidatures, missions proposées, historique, contacts, documents. Gestion des doublons (email, téléphone, règles de rapprochement) indispensable.
- **Vivier** : répondre instantanément à une demande type « 4 géologues d'exploration francophones, 7+ ans, expérience gold, disponibles pour la Guinée » → filtres → première liste. Actif central du nouveau site.
- **Offres d'emploi** : URL propre indexable (ex. `/jobs/senior-exploration-geologist-senegal/`) ; champs (poste, secteur, pays, localisation, mission, responsabilités, expérience, compétences, type de contrat, date, formulaire, offres similaires) ; **Schema.org JobPosting** sur la page individuelle ; expiration automatique.
- **Landing pages acquisition** : indépendantes des pages institutionnelles ; ex. `/lp/recrutement-geologue/`, `/lp/recrutement-minier/`, `/lp/executive-search-mining/`, `/lp/recrutement-finance-mining/`, `/lp/mise-a-disposition/`, `/lp/recrutement-senegal/`, `/lp/recrutement-guinee/`. Structure : Promesse → Problème → Profils recrutés → Méthode → Preuves → Délais/Process → Cas client → CTA → Formulaire. Pas de navigation parasite si elle nuit à la conversion.
- **Formulaire entreprise qualifiant** : société, nom, fonction, email pro, téléphone, pays, secteur, profil recherché, nombre de personnes, niveau, localisation, date souhaitée, commentaire. **UTM et source d'acquisition enregistrées automatiquement.**
- **Tracking obligatoire** : GA4, Google Search Console, GTM, pixels, suivi UTM, événements de conversion, CRM, ATS. Événements : `view_job`, `start_application`, `submit_application`, `upload_cv`, `view_service`, `view_mining_page`, `download_guide`, `use_tool`, `start_lead_form`, `submit_lead_form`, `click_phone`, `click_email`, `click_whatsapp`.
- **Exigences techniques SEO** : rendu HTML crawlable, URLs propres, HTTPS, responsive, Core Web Vitals, compression images, WebP/AVIF, lazy loading, sitemap XML (+ sitemap Jobs si besoin), robots.txt maîtrisé, canonicals auto-référencées, fil d'Ariane, pagination propre, 404 personnalisée, redirections serveur, Open Graph, metadata administrables, données structurées (Organization, BreadcrumbList, Article, JobPosting, Person si pertinent, FAQ seulement si justifié).
- **Migration (lot critique §29-34)** : jamais démarrer par la suppression ; dev en staging isolé non indexable ; inventaire AVANT migration (crawl exhaustif + GSC + Analytics + backlinks) → Master URL Migration File (Ancienne URL / trafic / backlinks / position / Nouvelle URL / Action KEEP-301-410-NOINDEX) ; redirections **serveur, sans chaînes** (A→C, jamais A→B→C), conservées indéfiniment sauf raison technique ; canonicals cohérentes avec sitemap/redirections ; suivi J+1/J+7/J+30/J+90.
- **Stack & archi (§35)** : séparer site public et application interne, reliés par API ; Site = acquisition, ATS = donnée métier, CRM = entreprises/opportunités.
- **Sécurité (§36)** : comptes/rôles/permissions, HTTPS, stockage CV sécurisé, journalisation, sauvegardes, restauration, politique de conservation, consentement, suppression/export candidat, contrôle d'accès aux CV, anti-spam, rate limiting, MFA admin recommandé. Aucun CV accessible via URL publique indexable.
- **Back-office sans développeur** : pages, articles, auteurs, secteurs, pays, métiers, offres, landing pages, formulaires, CTA, metadata, redirections, candidats, tags, statuts, utilisateurs, ressources, outils, menus.
- **Critères de recette (§40)** : 100 % des anciennes URL connues → 200/301/410 intentionnel ; 0 redirection 301 critique vers destination non pertinente ; 0 lien interne cassé ; 0 page stratégique en noindex ; 0 CV publiquement accessible ; 100 % des pages indexables avec canonical correcte ; 100 % des pages FR/EN concernées avec hreflang cohérent ; 100 % des formulaires avec attribution de source ; 100 % des offres avec URL individuelle + données structurées valides ; 100 % des candidatures reçues dans l'ATS avec CV associé ; tracking vérifié avant prod.
